# RaqeemOS — نظام إدارة المطابع

برنامج إدارة لمطابع الطباعة يعمل محليًا بالكامل (بدون إنترنت أو استضافة سحابية). كل نسخة مثبتة عند مطبعة مستقلة تمامًا ببياناتها.

## البنية التقنية

- **Electron** — يغلف التطبيق كبرنامج سطح مكتب لويندوز
- **Express (Node.js)** — خادم محلي يعمل داخل نفس عملية Electron، يستمع على `0.0.0.0:4310` حتى تصل له صفحة الزبون عبر الواي فاي المحلي
- **better-sqlite3** — قاعدة بيانات محلية بدون سيرفر منفصل، تُخزَّن في مجلد بيانات المستخدم
- **React + Vite + Tailwind** — واجهة المستخدم (RTL، عربي بالكامل)
- صفحتان إضافيتان خفيفتان (HTML/JS بدون بناء) تُقدَّمان مباشرة من Express لتُفتحا من الجوال ضمن نفس الشبكة:
  - `/portal/order.html` — صفحة الزبون لإرسال طلب أو رفع تصميم (عبر QR)
  - `/portal/owner.html` — لوحة المالك المصغّرة (ربح + طلبات) بتسجيل دخول PIN

## التشغيل في وضع التطوير

```powershell
# من جذر المشروع
npm install
npm --prefix client install

# تشغيل الخادم وواجهة React معًا (بدون Electron)
npm run dev

# أو لتشغيل نافذة Electron مباشرة في وضع التطوير (في نافذة PowerShell أخرى بعد تشغيل dev:client)
npm run dev:electron
```

- الخادم يعمل على المنفذ `4310`
- واجهة Vite تعمل على المنفذ `5173`
- أول تشغيل يُنشئ قاعدة بيانات SQLite تلقائيًا مع:
  - عامل افتراضي: **PIN = 1234** (صلاحية مالك) — غيّره فورًا من صفحة الإعدادات → العاملون
  - خدمتين تجريبيتين (كارت شخصي، فلكس) بأسعار قابلة للتعديل

## بناء نسخة التوزيع (exe) لويندوز

```powershell
npm run build:client
npm run rebuild   # يعيد بناء better-sqlite3 ليتوافق مع Electron
npm run dist
```

الناتج في مجلد `dist/` (مثبّت NSIS لويندوز).

## تفعيل واتساب التلقائي (اختياري)

المكتبة ثقيلة (تحمّل متصفح Chromium داخليًا) لذا هي غير مثبتة افتراضيًا:

```powershell
npm install whatsapp-web.js qrcode-terminal
```

ثم فعّل "الإرسال التلقائي عبر واتساب" من صفحة الإعدادات، وامسح رمز QR الذي سيظهر في الطرفية (Terminal) عند أول تشغيل لربط رقم واتساب المطبعة.

## النسخ الاحتياطي

نسخة تلقائية لقاعدة البيانات كل ٦ ساعات إلى مجلد `backups/` بجانب مجلد البيانات، أو إلى مسار مخصص (فلاشة/مجلد شبكة) من الإعدادات → النسخ الاحتياطي.

## هيكل المجلدات

```
electron/       نافذة سطح المكتب (main + preload)
server/         خادم Express + قاعدة البيانات + الخدمات
  db/           schema.sql + db.js
  routes/       نقاط API (auth, orders, stock, customers, ...)
  services/     منطق مشترك (نسخ احتياطي، واتساب، إعدادات)
  public/       صفحتا الزبون والمالك (تُقدَّم مباشرة عبر الشبكة المحلية)
client/         واجهة React (Vite + Tailwind)
data/           (يُنشأ تلقائيًا) قاعدة البيانات + الملفات المرفوعة
```
